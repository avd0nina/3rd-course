### №29. С использованием компьютера перечислить все совершенные двоичные коды длины 7 с кодовым расстоянием 3 с точностью до эквивалентности. Показать что все эти коды эквивалентны коду Хэмминга

n = 2^r - 1

7 = 2^r - 1 => r = 3

k = n - r = 7 - 3 = 4

|C| = 2^k = 2^4 = 16
