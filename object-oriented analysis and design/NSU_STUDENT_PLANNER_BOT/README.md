# 🎓 Бот-планировщик для студентов NSU

Телеграм-бот для планирования расписания занятий, управления домашним заданием, участия в очередях и уведомлений о сроках.
Никнейм в телеграм: @nsu_student_planner_bot

## 🚀 Запуск бота

```bash
python3 bot.py
```

После команды бот подключится к Telegram и начнёт работать.

## 📋 Основное меню

После запуска бота нажмите `/start` и вы увидите главное меню с пятью основными разделами:

### 1. 👥 Подключиться к группе
- **Описание:** Введите номер вашей учебной группы
- **Как использовать:** Нажмите кнопку "👥 Подключиться к группе" и введите номер группы (например, 130122)
- **Примечание:** После присоединения к группе вам станут доступны все остальные функции

### 2. 📚 Расписание
Управление расписанием занятий с четырьмя опциями:

**Создать расписание**
- Выберите день недели (Понедельник - Воскресенье)
- Введите название предмета
- Укажите время в формате: `ЧЧ:ММ-ЧЧ:ММ` (например, 09:00-10:30)

**Просмотр расписания**
- Выберите конкретный день или нажмите "Все дни"
- Бот выведет полное расписание с временем и предметами

**Редактировать расписание**
- Выберите день недели
- Выберите нужную запись
- Выберите действие: "Редактировать" или "Удалить"
- При редактировании выберите поле: предмет, время начала или время окончания
- Введите новое значение в требуемом формате

**Удалить расписание**
- Выберите запись
- Подтвердите удаление нажатием кнопки "Да"

### 3. 📝 Домашнее задание
Управление домашними заданиями с шестью опциями:

**Написать домашнее задание**
- Введите название предмета (бот добавит в ваш список)
- Введите описание задания
- Укажите срок выполнения в формате: `ГГГГ-ММ-ДД` (например, 2025-12-25)

**Просмотр активного домашнего задания**
- Бот выведет все активные задания с описанием и сроками

**Отметить домашнее задание выполненным**
- Выберите задание из списка
- Подтвердите выполнение нажатием кнопки "Да"

**Редактировать домашнее задание**
- Выберите задание
- Выберите поле для редактирования: описание или срок
- Введите новое значение

**Удалить домашнее задание**
- Выберите задание
- Подтвердите удаление нажатием кнопки "Да"

**Просмотр выполненного домашнего задания**
- Бот выведет список всех уже выполненных заданий

### 4. 📋 Очередь
Управление очередью в группе:

**Просмотр очереди**
- Выберите дату и предмет
- Бот выведет список студентов в очереди

**Присоединиться к очереди**
- Выберите дату и предмет
- Бот добавит вас в очередь и выведет вашу позицию

**Моя запись в очереди**
- Просмотрите информацию о вашей текущей позиции в очереди

**Редактировать запись в очереди**
- Удалите свою запись, если нужно выйти из очереди

### 5. 🔔 Уведомления
Управление уведомлениями о сроках и очереди:

**Уведомления о сроках выполнения**
- Включите/отключите уведомления о домашних заданиях
- Установите за сколько часов напоминать вам о сроке (целое число, например 24)

**Уведомления об очереди**
- Включите/отключите уведомления об изменении вашей позиции в очереди

## 📝 Форматы ввода

| Параметр | Формат | Пример |
|----------|--------|--------|
| Номер группы | Текст | 130122 |
| Предмет | Текст | Математика, Физика |
| Время | ЧЧ:ММ-ЧЧ:ММ | 09:00-10:30 |
| Дата | ГГГГ-ММ-ДД | 2025-12-25 |
| Часы напоминания | Целое число | 24 |

1. ✅ Подключение студента к группе

3. ✅ Просмотр расписания
4. ✅ Редактирование записи в расписании
5. ✅ Удаление записи из расписания
6. ✅ Запись домашнего задания
7. ✅ Просмотр активного домашнего задания
8. ✅ Редактирование домашнего задания
9. ✅ Отметить домашнее задание выполненным
10. ✅ Удаление домашнего задания
11. ✅ Присоединение к очереди
12. ✅ Просмотр очереди
13. ✅ Редактирование уведомлений

Все данные хранятся в локальной базе данных SQLite (`student_planner.db`). История сохраняется автоматически.
