ДЕКОМПОЗИЦИЯ БОЛЬШИХ ФИЧ НА МАЛЕНЬКИЕ ЗАДАЧИ

ПОРЯДОК РЕАЛИЗАЦИИ БОЛЬШИХ ФИЧ (ПО ЭТАПАМ)
1) ФИЧА A. Живое расписание НГУ + diff изменений
Причина: это базовый источник дисциплин/групп для остальных фич.

2) ФИЧА B. Личные и общие заметки по предметам
Причина: опирается на дисциплины и группы из A.

3) ФИЧА D. "Общий сбор" для группы
Причина: быстрый функционал командной коммуникации на существующих группах.

4) ФИЧА E. Чаты по предметам
Причина: зависит от актуального расписания и логики групп.

5) ФИЧА C. Gmail-синхронизация учебных писем
Причина: отдельный интеграционный блок (OAuth + фильтрация), лучше добавлять после стабильного ядра.

6) ФИЧА F. Умные уведомления и единая лента студента
Причина: агрегирует события из всех предыдущих фич, логично делать финальным этапом.

КАК НУМЕРОВАТЬ ЗАДАЧИ
Формат ID задачи: NSU-XXX (трехзначный номер, например NSU-001).
Формат ID в коммите: BOT-XXX (тот же номер, например BOT-001).

Диапазоны нумерации для текущего списка:
- A1-A9   -> NSU-001 ... NSU-009
- B1-B10  -> NSU-010 ... NSU-019
- C1-C10  -> NSU-020 ... NSU-029
- D1-D8   -> NSU-030 ... NSU-037
- E1-E8   -> NSU-038 ... NSU-045
- F1-F9   -> NSU-046 ... NSU-054

ПРАВИЛО ДЛЯ ВЕТОК
Каждая задача делается в отдельной ветке:
feature/NSU-XXX
Пример: feature/NSU-014

ПРАВИЛО ДЛЯ КОММИТОВ
Шаблон коммита:
[BOT-XXX] feat: что сделано в задаче

Примеры:
[BOT-014] feat: добавлен endpoint GET /notes/me и выдача личных заметок
[BOT-031] feat: добавлена проверка прав на общий сбор через Verificator
[BOT-044] feat: реализован автоинвайт участников в чат предмета

Мини-правила оформления:
- 1 задача = 1 ветка = 1-несколько коммитов с одним BOT-номером.
- В начале сообщения всегда [BOT-XXX].
- После feat: коротко и по делу, какой результат получен в рамках задачи.

A4. NSU Integration: реализовать вычисление diff между двумя снимками.
A5. NSU Integration: публиковать событие schedule_updated в Notifier.
A6. Gateway: добавить фильтры в GET /integration/schedule (по группе, дате, дисциплине).

A8. Telegram Bot: отдельная карточка "что изменилось" после обновления.
